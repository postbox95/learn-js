🔰 1.1 Hello, world!

JavaScript is the language of the web. It runs in your browser and makes pages interactive. Think of it as giving instructions to the browser.

Your first instruction: console.log(). It prints messages to the console (like a hidden panel for developers). You can open it with F12. We'll use it constantly to see what our code does.

In the example, we print a greeting and a number. Simple! You're already programming.

// your first program
console.log("Hello, future coder!");
console.log(2025);

📦 1.2 Variables & data types

Variables are like labelled boxes where you store information. let creates a box you can change later. const creates a box that cannot be reassigned (constant).

Different kinds of information have different data types:

  • number – for any number, like 25 or 3.14.
  • string – text, wrapped in quotes.
  • boolean – true or false.
  • undefined – a variable that hasn't been given a value yet.
  • null – intentionally empty.

The code below creates variables of each type and prints them.

let age = 25; // number
const name = "Alex"; // string
let isStudent = true; // boolean
let city; // undefined
let empty = null; // null
console.log(age, name, isStudent, city, empty);

🧮 1.3 Operators

Operators are action symbols. They let you do math, compare values, or combine conditions.

  • Arithmetic: + - * / % (plus, minus, times, divide, remainder).
  • Comparison: === (strict equal), !== (strict not equal), >, <. They give true/false.
  • Logical: && (AND – both true), || (OR – at least one true), ! (NOT – flips true/false).

The example shows each type in action.

let a = 15, b = 4;
console.log('sum:', a + b);
console.log('modulo:', a % b);
console.log('equal?', a === b);
console.log('logical AND:', a > 10 && b < 5);

⚖️ 1.4 Control flow (if / else)

Programs need to make decisions. if and else let you run different code based on conditions.

Think of it like a fork in the road: if the condition is true, go one way; otherwise, go another.

You can chain multiple conditions with else if. The example checks a score and prints a grade.

let score = 85;
if (score >= 90) {
  console.log('grade A');
} else if (score >= 75) {
  console.log('grade B');
} else {
  console.log('try again');
}

🔄 1.5 Loops

Loops repeat code. They save you from writing the same thing over and over.

  • for loop: when you know how many times to repeat (e.g., count 1 to 5).
  • while loop: repeats as long as a condition is true.

The first loop counts from 1 to 5. The second counts down from 3 to 1.

// for loop: count 1 to 5
for (let i = 1; i <= 5; i++) {
  console.log('number', i);
}

// while loop
let count = 3;
while (count > 0) {
  console.log('countdown', count);
  count--;
}

⚙️ 1.6 Functions basics

Functions are reusable recipes. You define a block of code once, give it a name, and then you can "call" it whenever you need it.

Functions can take parameters (inputs) and return a value (output). The example function greet takes a name and returns a greeting.

This keeps your code DRY (Don't Repeat Yourself).

function greet(name) {
  return 'Hello, ' + name + '!';
}
let message = greet('Sam');
console.log(message);

🏷️ 2.1 Objects

Objects bundle related data together. They use key-value pairs: each piece of data has a name (key) and a value. Think of a student: they have a firstName, age, enrolled status.

You can access values with dot notation (student.firstName) or bracket notation (student['age']). Objects are fundamental for organizing complex data.

let student = {
  firstName: 'Emma',
  age: 20,
  enrolled: true
};
console.log(student.firstName);
console.log(student['age']);

📚 2.2 Arrays & methods

Arrays are ordered lists. They can hold anything: numbers, strings, even objects.

Modern JavaScript gives us powerful methods to work with arrays without writing loops manually:

  • map() – transforms every element, returns a new array.
  • filter() – keeps only elements that pass a test.
  • forEach() – does something for each element.

The example doubles all numbers and then keeps only the even ones.

let numbers = [2, 5, 8, 10];
let doubled = numbers.map(n => n * 2);
console.log('doubled:', doubled);
let even = numbers.filter(n => n % 2 === 0);
console.log('even:', even);

🌲 2.3 DOM (Document Object Model)

The DOM is the bridge between JavaScript and HTML. When a web page loads, the browser creates a tree of objects representing every element. JavaScript can modify these objects – changing text, styles, adding or removing elements.

You first select an element (e.g., with getElementById), then you can change its innerHTML or style. Below, we change the blue demo box.

I'm a demo box 🟦
// change the blue box above
let box = document.getElementById('dom-demo');
box.innerHTML = '✨ text updated by JS!';
box.style.backgroundColor = '#f4c542';

⏱️ 2.4 Events

Events are user actions like clicks, key presses, or mouse movements. You can make your page respond by attaching an event listener to an element.

addEventListener('click', function) tells the browser: "when this element is clicked, run this function." The function can change the page, fetch data, etc.

Below, we attach a click listener to the test button. Try clicking it, or run the example to simulate a click.

👉 click the button — or run example

// Attach click event to the button
let btn = document.getElementById('testButton');
btn.addEventListener('click', function() {
  document.getElementById('eventMsg').innerText = '✅ button clicked!';
});

🔁 2.5 JSON

JSON is a lightweight data format used everywhere – APIs, config files, storage. It looks almost exactly like a JavaScript object, but with double‑quoted keys.

JSON.stringify() converts a JavaScript object into a JSON string (to send or save). JSON.parse() converts a JSON string back into an object (to use in code).

This is essential when talking to servers or using localStorage.

let person = { name: 'Mia', age: 28 };
let jsonString = JSON.stringify(person);
console.log('JSON:', jsonString);
let backToObject = JSON.parse(jsonString);
console.log('parsed name:', backToObject.name);

⏳ 3.1 Asynchronous JavaScript

Sometimes code takes time – like waiting for data from the internet or a timer. JavaScript doesn't stop; it keeps running other code. That's asynchronous programming.

Promises are like an IOU note: “I promise I'll give you a result later, either success or failure.” You use .then() to handle the success, and .catch() for errors.

Async/await is a modern way to write promise-based code that looks like normal step-by-step code. Just mark a function async, then inside it use await to wait for a promise to resolve.

In the example, we create a promise that waits 1 second, then logs a message. Then we do the same with async/await.

// Promise that resolves after 1 second
const wait = new Promise((resolve) => {
  setTimeout(() => resolve('done!'), 1000);
});
wait.then(msg => console.log('promise resolved:', msg));

// async/await version
(async function() {
  let msg = await wait;
  console.log('async/await:', msg);
})();

🌐 3.2 Fetch & APIs

APIs are like waiters in a restaurant – you ask for something (data), and they bring it from the kitchen (server). The fetch() function is how we make that request in JavaScript.

fetch('url') returns a promise. First, we get a response object; we call .json() on it to extract the data (another promise). Then we can use the actual data. Always handle errors with .catch().

Below we fetch a sample to-do item from a free test API (JSONPlaceholder) and print it.

fetch('https://jsonplaceholder.typicode.com/todos/1')
  .then(response => response.json())
  .then(data => console.log('TODO:', data))
  .catch(err => console.error('fetch error:', err));

✨ 3.3 Modern ES6+ features

Destructuring is a shortcut to pull values out of arrays or objects into variables. Instead of writing const first = colors[0], you can do const [first] = colors.

Spread operator (...) expands elements. You can copy an array, combine arrays, or add properties to an object without mutating the original.

These features make code cleaner and less error‑prone.

// Array destructuring
const colors = ['red', 'green', 'blue'];
const [first, second] = colors;
console.log('first color:', first);

// Object destructuring
const user = { name: 'Zoe', age: 24 };
const { name, age } = user;
console.log(name, age);

// Spread operator
const moreColors = [...colors, 'yellow', 'purple'];
console.log('spread:', moreColors);

🐞 3.4 Error handling & debugging

Errors happen – but we can handle them gracefully. Use try { ... } catch (error) { ... } to wrap code that might fail. If an error occurs inside try, the catch block runs. The finally block always runs, no matter what.

You can also throw your own errors to signal something went wrong.

The example intentionally creates an “division by zero” error and catches it.

try {
  let result = 10 / 0;
  if (!isFinite(result)) throw new Error('division by zero?');
  console.log('result:', result);
} catch (error) {
  console.error('caught:', error.message);
} finally {
  console.log('cleanup (always runs)');
}

🎣 4.1 Advanced functions (closures)

A closure happens when a function “remembers” the variables from its birthplace, even after the birthplace has finished running.

Imagine a function that creates a counter: it defines a variable count and returns another function that increments and returns count. That inner function has a closure over count – it can still access it later. Each call to the counter updates the same count.

Closures are used for data privacy, function factories, and many advanced patterns.

function makeCounter() {
  let count = 0;
  return function() {
    count++;
    return count;
  };
}
const counter = makeCounter();
console.log(counter()); // 1
console.log(counter()); // 2

🏛️ 4.2 OOP (classes, prototypes)

Object‑Oriented Programming helps you organize code by creating blueprints (classes) for objects. A class defines properties and methods. You create instances with new.

With inheritance (extends), a class can reuse and extend another class. For example, a Dog class inherits from Animal and can override the speak method.

Behind the scenes, JavaScript uses prototypes – objects inherit from other objects. Classes are just a cleaner syntax for that.

class Animal {
  constructor(name) { this.name = name; }
  speak() { console.log(`${this.name} makes a sound`); }
}
class Dog extends Animal {
  speak() { console.log(`${this.name} barks`); }
}
const pet = new Dog('Rex');
pet.speak();

🔍 4.3 The 'this' keyword

this is a special keyword that refers to the context in which a function is called. It can be tricky:

  • In a regular function, this refers to the object that called it (e.g., person.greet() → this = person).
  • In an arrow function, this is taken from the surrounding scope (lexical this) – it doesn't get its own.
  • If you call a function without an object, this is the global object (or undefined in strict mode).

The example shows the difference: greet uses the object’s name, while arrowGreet uses the outer this (likely window, which has no name).

const person = {
  name: 'Alex',
  greet: function() { console.log('Hello, ' + this.name); },
  arrowGreet: () => console.log('Hello, ' + this.name) // 'this' is outer scope (likely window)
};
person.greet(); // Hello, Alex
person.arrowGreet(); // Hello, undefined (in strict mode)

💾 4.4 Browser storage

Browsers give us small databases to store data on the user's device.

localStorage saves data with no expiration – it stays even after you close the browser. sessionStorage clears when the tab is closed. Both store strings, so you often use JSON.stringify and JSON.parse for objects.

Methods: setItem(key, value), getItem(key), removeItem(key).

Below, we store a name and retrieve it. Try the interactive buttons too!

Stored name: (not set)

// Save and load from localStorage
localStorage.setItem('username', 'Alex');
let name = localStorage.getItem('username');
console.log('from storage:', name);

⚡ 4.5 Design patterns & performance

Debouncing is a performance trick: it ensures a function is not called too often. For example, if you have a search input that fetches results as you type, you don't want to fetch on every keystroke – you wait until the user pauses.

How it works: every time the event fires, we clear the previous timer and set a new one. The function only runs after the specified delay without any new calls.

The example creates a debounced sayHi that will only execute once after 1 second, even if we call it three times in a row.

function debounce(fn, delay) {
  let timer;
  return function(...args) {
    clearTimeout(timer);
    timer = setTimeout(() => fn.apply(this, args), delay);
  };
}
const sayHi = debounce(() => console.log('hi (debounced)'), 1000);
sayHi(); sayHi(); sayHi(); // only one 'hi' after 1 sec
